Submission Converter

Internal tool — not linked from the site. Turns the Approved rows in Game Submissions.xlsx into JSON shaped like the existing VSR/Stock data files. Nothing here uploads anywhere; the file is only read in your browser.

  1. In the Google Sheet, set each row's Approval Status to Approved or Rejected.
  2. File → Download → Microsoft Excel (.xlsx).
  3. Load that file below.
  4. Download the JSON for whichever mod(s) have approved rows.
  5. Merge the downloaded JSON into the right year's file under data/vsr/ or data/stock/ (it's keyed by month → date → map, same as those files), then run python scripts/main.py.
